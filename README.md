# HastakalaAssist 🧶📱

HastakalaAssist is an Android application designed to help artisans and small craft businesses manage their sales and gain simple business insights through an intuitive mobile interface.

The application provides dedicated screens for tracking sales, viewing analytics, and accessing AI-inspired business insights. The project was developed using modern Android development technologies with a focus on clean UI, usability, and practical business workflows.

## ✨ Features

- 📊 **Business Dashboard**
  - View total items sold
  - Identify best-selling products
  - Get a quick overview of sales performance

- 🛒 **Sales Management**
  - Add sales records
  - Select product category
  - Select product color
  - Specify quantity
  - Display successful save confirmation

- 📈 **Sales Analytics**
  - View total items sold
  - Identify best-selling products
  - View product-wise sales breakdown
  - Visual representation of product distribution

- 🤖 **AI Insights**
  - Business growth score
  - Personalized business suggestions
  - Product trend and promotion insights

- 🔥 **Firebase Integration**
  - Firestore integration for storing sales data
  - Firebase configuration for cloud-based data management

## 🛠️ Tech Stack

- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **Design:** Material 3
- **Architecture/Structure:** Component-based Android UI
- **Database/Backend:** Firebase Cloud Firestore
- **Navigation:** Jetpack Compose Navigation
- **Build System:** Gradle Kotlin DSL
- **Development Environment:** Android Studio
